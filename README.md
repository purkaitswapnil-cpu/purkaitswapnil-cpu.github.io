# Taarini website (published build)

This repository holds the built, static Taarini storefront that GitHub Pages serves at
https://purkaitswapnil-cpu.github.io. Don't edit files here by hand: the source lives in the
private `taarini` repository, and this folder is regenerated from it with
`SITE_URL=https://purkaitswapnil-cpu.github.io npm run build:static`.
